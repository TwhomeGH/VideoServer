# Tutorial：從零做一個小功能

這系列不是 API 參考，而是**照著做**的練習。每個題目都只改一小段，完成後要能回答：

- 我改了哪些檔案？
- 為什麼改這裡？
- 怎麼確認它真的有效？
- 下一個功能會重用哪個部分？

| 題目 | 類型 | 狀態 |

| [01 複製影片 ID](01-frontend-copy-id.md) | 純前端、i18n | 完成 |
| 02 全域通知元件 | 前端架構、Context | 下一個 |
| 03 有無封面篩選 | API + 前端 | 規劃中 |
| 04 影片收藏 | schema + API + 前端 | 規劃中 |

## 使用方式

1. 從 `npm run dev` 開始，不要只啟動 Vite。
2. 一次只做一題；每題都有「檢查點」。
3. 做完先跑題目給的驗證指令，再進下一題。
4. 不要把下一個題目的改動一起塞進目前題目。
5. 完成後把實際 diff、指令輸出與畫面記錄回題目文件。

## 為什麼從純前端開始

先建立「改檔 → Vite 熱更新 → 看畫面 → build」的循環，不需要同時處理 SQLite migration、API、OpenAPI 與 Docker。等這個循環熟了，再進 API 與 schema。
