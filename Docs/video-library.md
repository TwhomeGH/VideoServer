# 影片庫分頁與查詢

在「影片庫」填寫條件後按「套用查詢」。搜尋比對標題與簡介；Tag 與分類使用完整名稱，可與儲存池、18+ 標記組合。按「清除條件」恢復全部影片。

每頁可選 12、24、48 或 100 筆，預設 24 筆。可依最新匯入、最早匯入或標題排序，使用上一頁／下一頁瀏覽。切換條件會回到第一頁；無結果時會顯示提示。

標記「未標示 18+」只表示管理者未勾選，不能解讀為已審核或適合所有年齡。離線影片仍會列出，但無法播放。

頁面每五秒重新取得目前查詢；新增匯入可能使排序與頁碼內容移動。篩選目前保留於本次管理頁面，重新整理瀏覽器後回復預設。

## API

`GET /api/v1/library` 需要管理員登入。原有 `videos` 欄位改為當頁內容，新增 `pagination`：`page`、`pageSize`、符合條件的 `total` 及整庫的 `totalVideos`。使用此 API 的程式須按頁讀取，不能假設一次取得全庫。

| 參數 | 預設 | 用途 |
| --- | --- | --- |
| `page` | `1` | 頁碼，超出結果範圍時回到最後一頁 |
| `pageSize` | `24` | 每頁 1–100 筆 |
| `q` | 空白 | 標題或簡介包含文字；百分號與底線不視為萬用字元 |
| `tag` | 空白 | 完整 Tag，沿用既有 Tag 小寫索引比對 |
| `category` | 空白 | 完整分類名稱 |
| `poolId` | 空白 | 指定儲存池 |
| `adult` | 空白 | `true` 為已標示，`false` 為未標示；空白不篩選 |
| `sort` | `newest` | `newest`、`oldest` 或 `title` |

無結果時 `videos` 為空陣列、頁碼為 1。非法分頁、排序、內容標記或過長文字回應 400。來源檔案可用狀態只檢查當頁；總覽不再為了統計而開啟全庫影片檔案。

SQLite 內建標題搜尋與排序僅對 ASCII 字母提供大小寫折疊，中文使用文字本身比對；目前未加入全文檢索、模糊搜尋或分類管理。
